# Default — шаблон яйца

Базовое яйцо из кубов. Остальные яйца делаются из него: копируется `models/egg-default.blend`, меняется цвет материала или текстура, форма остаётся.

## Файлы

- `models/egg-default.blend` — редактируемый исходник, объект `EggDefault`, материал `EggStud`.
- `exports/egg-default.fbx`, `exports/egg-default.glb` — экспорт для Roblox, только меш.
- `textures/studtexture.png` — studs, копия `Assets/Textures/studtexture.png` (500×500, прозрачный фон, сетка 4×4).

## Форма

Кубы расставлены формулой, не вручную. Куб `S = 0.155`. Ячейка `(i, j, l)` заполнена, если её центр `((i+0.5)·S, (j+0.5)·S, l·S)` внутри яйца:

`z = Z / RH`, `r = √(X² + Y²) / (RW · (1 − TAPER·z))`, условие `r² + z² ≤ TH`.

`RW = 0.96`, `RH = 1.17`, `TAPER = 0.16`, `TH = 0.95`. Сетка X/Y сдвинута на полкуба: ширина чётная, модель симметрична по X, Y и при повороте на 90°. Строятся только внешние грани.

Итог: 12 кубов в ширину, 15 в высоту; 1.86 × 1.86 × 2.325; 808 граней, 1616 треугольников. Pivot — центр низа.

## Studs и цвет

UV — плоская проекция по оси нормали каждой грани. Один stud ≈ 1.6 куба (`K = 1.6`), studs намеренно не совпадают с гранями.

В Blender цвет = `studtexture` поверх белого × персиковый `(0.87, 0.42, 0.24)` linear. В FBX/GLB текстура не встроена. В Roblox: MeshPart `TextureID` = studtexture, цвет яйца — свойство `Color` (просвечивает через прозрачный фон текстуры).

## Пак яиц

В том же `egg-default.blend` справа от `EggDefault` в ряд (шаг 3 по X) стоят яйца пака: `Egg01_Moss`, `Egg02_Birch`, `Egg03_Mushroom`, `Egg04_Acorn`, `Egg05_Enchanted`. Второй ряд (Y = 6, шаг 3 по X) — пустынный пак: `Egg06_Cactus`, `Egg07_Pharaoh`, `Egg08_Sandstorm`, `Egg09_Scorpion`, `Egg10_Oasis`. Их строит `tools/blender/build-egg-pack.py` (запуск внутри Blender с открытым файлом; повторный запуск пересоздаёт `Egg0N_*`).

Форма и studs — из шаблона. Корпус и декор симметричны как шаблон (зеркала X и Y, поворот на 90°): узоры считаются по «сложенным» координатам кубов, без случайности. Исключения ставятся один раз, без поворота: кобра Pharaoh, хвост Scorpion и парящее кольцо кубиков Sandstorm. Кубы чередуют два близких оттенка (шахматка), материалы `Egg<Имя>_*` используют ту же studtexture.

У лесного пака декор (листья, папоротник, камни, грибочки, кристаллы, руны) стоит только на корпусе, на макушке ничего не торчит. У пустынного на макушке стоят цветок (Cactus), кобра (Pharaoh), хвост (Scorpion) и пальма (Oasis). Он тоже из кубов: половинного размера, на сетке, выровненной с сеткой яйца, без поворотов. Каждый элемент описан пиксельным узором для передней стороны и автоматически отзеркален и повернут на 4 стороны.

У грибного и жёлудя верх взят из более широкого яйца, а нижние ряды шляпки — ещё шире: получается нависающий бортик. У жёлудя бортик тёмный, чтобы шляпа отделялась от скорлупы. Руны и кристаллы зачарованного яйца — emissive-материалы.

Экспорт для Roblox: `assets/items/eggs/pack/exports/roblox-import-v02/` — все 11 яиц; `roblox-import-v01/` — только лесной пак (см. `README_IMPORT.md` там), собирается `tools/blender/export-egg-pack.py`.

## Статус

FBX повторно импортирован в Blender: меш и размеры сохранены. Пак импортирован в Studio: шаблоны — MeshPart в `ServerStorage.Assets.Items.Eggs` (Color — акцент яйца; CollisionFidelity у лесных PreciseConvexDecomposition, у пустынных Default). Игра использует их для яиц Forest и Desert (см. `docs/gameplay.md`), DefaultEgg — для яиц в руке и на базе. Иконки — `assets/items/eggs/icons/` (Roblox ID в `manifest.json`).
