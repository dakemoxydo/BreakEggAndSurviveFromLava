# Wooden — текущая модель v04

Голова из семи крупных деревянных блоков с симметричными заострёнными концами. Форма и синий металлический ромб доработаны по двум фото оригинальной игры.

Обе стороны зеркально симметричны. Studs выполнены плоской текстурой пользователя, шаг 0.55 единицы. Выпуклых квадратов нет. Pivot экспорта находится в точке хвата на рукояти.

Общий редактируемый исходник: `../pack/models/pickaxes-asset-pack-v01.blend`, сцена `Review_Wooden_Stone`, коллекция `01_Wooden_Reference_v04`. Отдельные файлы FBX и GLB: `exports/wooden-pickaxe-reference-v04.fbx` и `exports/wooden-pickaxe-reference-v04.glb`. Прозрачная иконка: `icons/wooden-pickaxe-reference-v04.png`. Прямой и боковой виды находятся в `models`.

528 треугольников. Закрытая геометрия, без вырожденных треугольников и UV. FBX/GLB повторно импортированы в Blender, размеры и текстура сохранены. В Roblox Studio модель ещё не импортирована.

Модель ожидает визуального отзыва. Предыдущие версии сохранены для сравнения.
