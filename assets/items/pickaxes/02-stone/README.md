# Stone — текущая модель v01

Голова из серых каменных блоков с острыми гранёными концами. Рукоять, металлические обоймы и масштаб studs согласованы с деревянной киркой.

Обе стороны зеркально симметричны. Studs выполнены плоской текстурой пользователя, шаг 0.55 единицы. Выпуклых квадратов нет. Pivot экспорта находится в точке хвата на рукояти.

Общий редактируемый исходник: `../pack/models/pickaxes-asset-pack-v01.blend`, сцена `Review_Wooden_Stone`, коллекция `02_Stone_Reference_v01`. Отдельные файлы FBX и GLB: `exports/stone-pickaxe-reference-v01.fbx` и `exports/stone-pickaxe-reference-v01.glb`. Прозрачная иконка: `icons/stone-pickaxe-reference-v01.png`. Прямой и боковой виды находятся в `models`.

464 треугольников. Закрытая геометрия, без вырожденных треугольников и UV. FBX/GLB повторно импортированы в Blender, размеры и текстура сохранены. В Roblox Studio модель ещё не импортирована.

Модель ожидает визуального отзыва. Предыдущие версии сохранены для сравнения.
