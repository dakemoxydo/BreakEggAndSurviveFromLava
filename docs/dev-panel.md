# DevPanel — тестовая панель владельца

Читать перед изменением DevPanel или команд `DevAction`. Контракт команд — [network-api.md](network-api.md#devaction--remotefunction); общий UI — [ui.md](ui.md). Исключение из UI-07: панель видна только UserId из `DevTools.Owners`.

Тестовая панель владельца (`src/shared/DevPanel.luau`, отдельный ScreenGui `DevPanel`, DisplayOrder 20). Клиент монтирует её, только когда сервер поставил игроку `DevAccess`; каждую команду `DevAction` сервер заново сверяет с `DevTools.Owners` ([network-api.md](network-api.md)). Обычный игрок панели и кнопки не видит.

- Кнопка `DevToggle` («DEV», 64×44) стоит в верхней строке сразу за системными кнопками Roblox (`GuiService.TopbarInset.Min.X + 4`) и сдвигается вместе с ними; окно чата под строкой не перекрывает. F2 тоже открывает и закрывает панель.
- Окно до 900×720 единиц открывается по центру экрана, не выше верхней строки, перетаскивается за шапку; появление — проявление CanvasGroup с подъёмом на целые пиксели, без масштаба. В шапке — окружение и режим сохранений, FPS и ping; внизу — ответ сервера.
- Слева — карточка цели (аватар, имя; клик открывает Players) и вертикальные вкладки; справа — прокручиваемое содержимое на тёмной подложке. Команды Economy, Pets, тосты и действия Players применяются к выбранной цели (по умолчанию — владелец). Данные цели обновляются после каждой успешной команды и раз в 2 s, пока панель открыта.
- Players: карточки всех игроков сервера (аватар, имя, Cash, Rebirths; владелец первым); профиль цели; 14 плиток статистики; действия Go to, Bring, Ragdoll, Drop cargo, Respawn, Kick (повторное нажатие; себя нельзя), телепорт цели на базу или в биомы; строки питомцев на базе и в рюкзаке (перенос на базу/в рюкзак, вес — ввод числа + Enter, удаление повторным нажатием) и яиц (удаление). До 60 строк на список.
- Economy: быстрые кнопки и поле числа для Cash и Speed (Add/Set; суффиксы K, M, B, T, Qa, Qi), Rebirth, всё снаряжение, максимум базы, награды, офлайн-доход. Pets: выдача любого вида питомцем или яйцом с весом 1–1000 kg или своим, Discover all, Hatch base, Clear all. World:
  - Лава (весь сервер): волна сейчас, Stop wave, пауза волн, интервал 10/30/60/120 s (по умолчанию `GameConfig.LavaInterval`); в заметке — идёт волна, пауза или секунды до следующей.
  - Полевые яйца (весь сервер): Titanic, Refill HP — всем целым яйцам полное HP.
  - Для цели: иммунитет к лаве, One-hit (удар обнуляет HP яйца), результат вылупления — Normal или принудительная редкость (Common…Mythic; Titanic Egg всегда Titanic), удача ×1/×10/×100/×1K.
  - Broadcast: тост всем игрокам (Info/Danger/Event); текст проходит фильтр Roblox `TextService`. Тестовые тосты — только цели.
  - Переключатели живут на сервере в `Adventure.dev` до перезапуска сервера; личные — до выхода игрока, не сохраняются. UI: открыть окно через `UIController`; в Studio — `PreviewViewport`.
- Character (только у владельца локально, на сервер не уходит): Fly (WASD по камере, E/Space вверх, Q/Ctrl вниз, Shift ×3; 50–500 studs/s), Noclip, Freecam (Scriptable-камера, ПКМ — обзор, 20–400 studs/s; выключение возвращает камеру персонажу).
- Data (цель): хранилище, режим, время последнего сохранения (`LastDataSaveAt`), размер профиля; Save now — сохранение без ограничения частоты; Reload — перечитать. Away 1/8/24/48h начисляет офлайн-доход по формуле входа, как будто цель ушла сейчас и вернулась через N часов (учитывается не больше `OfflineLimitSeconds`); для себя панель закрывается и показывается окно Offline Cash. Reset profile (только Studio, повторное нажатие) заменяет сохранённый профиль шаблоном и кикает цель. Внизу — Profile.Data по ключам, только чтение (выделяется и копируется), до 15 000 символов.
- Server (весь сервер, обновление раз в 2 s): FPS сервера и физики, память сервера и клиента, игроки, время работы, число объектов Workspace, версия place, хранилище; последние 40 предупреждений и ошибок сервера и клиента (показ — 20 новых), Clear.
- В live изменение данных других игроков запрещено сервером; карточка цели и профиль пишут «read-only (live)», такие кнопки неактивны.

## Исходники

| Файл | Ответственность |

| `src/server/DevTools.luau` | `DevAction`, проверка владельца и цели, `DevAccess` |
| `src/client/DevPanel.client.luau` | Монтирование ScreenGui `DevPanel` при `DevAccess` |
| `src/shared/DevPanel.luau` | Окно, левая колонка, вкладки Economy/Pets/World/Character/UI, обновление данных цели |
| `src/shared/DevKit.luau` | Секции, сетки, кнопки с подтверждением, поле числа (`Kit.parse`) |
| `src/shared/DevPlayers.luau` | Вкладка Players |
| `src/shared/DevData.luau` | Вкладки Data и Server, журнал клиента |
| `src/shared/DevCharacter.luau` | Fly, Noclip, Freecam (клиент) |
