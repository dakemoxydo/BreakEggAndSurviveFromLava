# Оптимизация UI

Инвентарь на широком экране расположен над хотбаром, занимает около половины ширины и 40% высоты viewport. Хотбар выровнен по ширине панели. Узкие экраны сохраняют вкладки сверху и два ряда слотов.

Изменения производительности:

- App объединяет изменения атрибутов в один отложенный проход и обновляет только изменившиеся поля. При нулевом EventRemaining секундный таймер не создаёт новую таблицу состояния.
- JSON питомцев и яиц декодируется только при изменении соответствующей строки. Settings получает только свои данные; содержимое Shop кэшируется по параметрам экрана и категории.
- Inventory, Hotbar, Settings, кнопки и поверхности используют React.memo. Обработчики навигации, серверных действий и Tool сохраняют идентичность; обновления баланса не перестраивают сетку и хотбар.
- Backpack подписывается на контейнеры один раз, отслеживает отдельные Tool и только свойства Name, TextureId, UIIcon, PlacementKind. Перенос между Backpack и Character не переподключает все обработчики. Состояние обновляется только при изменении состава, слотов, экипировки или оформления.
- Содержимое кнопок и binding масштаба переиспользуются. Ripple сохраняет скорость при изменении цели; пружины критически затухают. Точность реакций кнопок соответствует малому визуальному смещению. Reduced Motion останавливает пружины и сразу устанавливает целевое состояние.
- Исправлена проверка drag: начальная и конечная позиции мыши для подавления клика используют одинаковые координаты.

## Проверка Studio MCP

Временные копии модулей с счётчиками RenderCount монтировались в невидимый ScreenGui. Сценарий: 20 изменений баланса с интервалом 0.03 секунды. Счётчики измеряют вызовы React-компонентов, а не FPS и не длительность кадра. Серверные обновления могут добавить вызовы App.

| Экран | До | После |
|---|---:|---:|
| Инвентарь: вызовы Inventory | 20 | 0 |
| Инвентарь: вызовы Hotbar | 20 | 0 |
| Shop: вызовы кнопок | 704 | 147 |

После уменьшения панели навигационный HUD остаётся видимым на широком экране, поэтому его кнопки могут обновляться независимо от инвентаря. Отдельно проверены не относящиеся к UI атрибуты Tool: сетка и хотбар не перерисовываются.

Регрессии проверены: экипировка/снятие, выделение слота, drag-обмен, назначение Tool в другой слот, поиск, обновление UIIcon, 14 предметов при 10 слотах, быстрые переключения основных окон, серверный Equip/Unequip питомца, Reduced Motion и респавн. Ошибок UI в консоли не обнаружено. Физические touch/gamepad и FPS на слабом устройстве не измерялись. Временные benchmark-модули удалены после проверки.
