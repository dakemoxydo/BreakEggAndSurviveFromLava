# Инвентарь и Backpack — источник истины

Контракт утверждён пользователем 2026-10-08. Определяет назначение общего инвентаря, состав предметов и их переходы между рукой, Backpack и базой. Отображение и маршруты открытия — в [ui.md](ui.md).

## Инварианты

- **INV-01** — Инвентарь — классический Roblox Backpack (Tool, Backpack, Character) с кастомным UI. Взять предмет в руку = экипировать Tool в Character; повторный выбор возвращает его в Backpack. Это не размещает питомца на базе и не меняет его доход.
- **INV-02** — Каждый неразмещённый питомец и каждое переносимое яйцо — отдельный Tool с `InventoryId`, равным ID сохраняемой записи. Несколько таких предметов хранятся одновременно; новый Tool не заменяет остальные.
- **INV-03** — Размещённые питомцы, полевые яйца и размещённые растущие яйца не являются предметами Backpack.
- **INV-04** — В Inventory нет EquipPet/UnequipPet, Equip Best, Merge, управления слотами базы, доходом или ростом яиц. Это делают правые панели Pets и Eggs.
- **INV-05** — Вкладки только Pets и Eggs. Кирки, биты и другие инструменты лежат в хотбаре или в первой вкладке, без отдельной категории.
- **INV-06** — Не расширять инвентарь новыми системами, категориями и функциями. Кнопки и подписи на референсе не являются запросом на механики.
- **INV-07** — Размещение, Merge, респавн и повторный вход не дублируют и не теряют сохраняемые предметы.

## Назначение

Общий инвентарь на Backquote («`» / «ё») заменяет стандартный Roblox Backpack только визуально. Основа поведения — стандартные Tool, Backpack и Character. Хотбар и окно инвентаря отображают одну систему предметов.

Взять предмет в руку означает экипировать Tool в Character. Это действие не размещает питомца на базе, не включает его доход и не меняет его состояние equipped в сохраняемой записи. Повторный выбор снимает Tool из руки в Backpack.

## Состав

- Кирка, бита и другие обычные инструменты — Tool.
- Каждый принадлежащий игроку питомец, ещё не размещённый на базе, — отдельный Tool. Несколько таких питомцев могут одновременно находиться в Backpack.
- Каждое принадлежащее игроку переносимое яйцо для размещения — отдельный Tool. Такие яйца могут одновременно храниться с питомцами и инструментами.
- Питомцы, размещённые на базе, не отображаются как предметы Backpack.
- Полевые яйца, которые разбивают киркой, не являются предметами Backpack.
- Размещённые растущие яйца относятся к базе и не отображаются как предметы Backpack.

Вкладки Pets и Eggs фильтруют реальные Tool. Eggs содержит переносимые яйца; первая вкладка содержит остальные предметы вне хотбара, без отдельной категории инструментов. PetInventory и GrowingEggs не являются источником карточек этого окна.

Сейчас переносимые яйца выдаёт Merge. Будущие отдельно покупаемые яйца должны поступать в тот же Backpack как обычные Tool. Этот контракт не означает, что покупка яиц уже реализована.

## Переходы владения и размещения

| Событие | Результат |
|---|---|
| Добыча доставлена через Safe Zone | Каждый питомец становится сохранённой собственностью игрока и получает свой Tool |
| Игрок берёт питомца или яйцо в руку | Соответствующий Tool перемещается из Backpack в Character; размещение на базе не меняется |
| Игрок снимает предмет из руки | Тот же Tool возвращается в Backpack |
| Игрок размещает питомца на базе | Существующая запись по ID становится размещённой; её Tool удаляется |
| Игрок убирает питомца с базы | Питомец перестаёт приносить доход; тот же сохраняемый ID получает Tool в Backpack |
| Игрок размещает переносимое яйцо | Яйцо по выбранному ID удаляется из backpackEggs и становится растущим яйцом на базе; его Tool удаляется |
| Игрок получает ещё один предмет | Новый Tool добавляется, остальные предметы сохраняются |
| Merge удаляет исходных питомцев | Их Tool удаляются; результат добавляется отдельным переносимым яйцом |
| Респавн или повторный вход | Все сохранённые неразмещённые питомцы и переносимые яйца восстанавливаются как Tool |

InventoryId связывает Tool с сохраняемой записью. Выбор одного предмета не заменяет остальные. Размещение не создаёт второй экземпляр собственности. Полевой груз до доставки в Safe Zone остаётся отдельной системой.

## Разделение интерфейсов

Inventory открывается Backquote и кнопкой рядом с Settings. В нём нет EquipPet, UnequipPet, Equip Best, управления активными слотами базы, доходом или ростом размещённых яиц.

Правая Pets управляет питомцами на базе и их активностью. Правая Eggs / Growing Eggs управляет размещёнными растущими яйцами. Эти панели сохраняют отдельные маршруты открытия; совпадение названий с вкладками Inventory не объединяет их назначения.

## Хотбар и сетка

Хотбар содержит десять слотов. При открытом Inventory видны все слоты; при закрытом — занятые. Сетка показывает Tool, не назначенные в хотбар. Предмет доступен в одной позиции интерфейса, независимо от того, находится его Tool в Backpack или Character.

Перетаскивание переносит Tool между сеткой и хотбаром и меняет местами занятые слоты. Новые Tool занимают свободные слоты. Предмет, вручную убранный из хотбара, остаётся в сетке. По умолчанию бита в слоте 1, кирка в слоте 2; их слоты остаются свободными, пока Tool пересоздаётся. Раскладка сохраняется в профиле (`hotbar`: ключ предмета → слот 1–10, 0 — только сетка; ключ — `InventoryId`, `Pickaxe` или имя `Lava Bat`) и восстанавливается при входе, включая предметы, убранные в сетку. Клиент ждёт `HotbarLayout` до раскладки Tool и отправляет изменения через `SetHotbar` с задержкой 1 s. Перемещение Tool в руку и обратно сохраняет назначенный слот. Поиск фильтрует предметы; пустой инвентарь не показывает инструкции посередине.

При переносе отображается изображение и имя исходного Tool, а допустимое место назначения подсвечивается. Декор не принимает ввод; отпускание не экипирует предмет дополнительно. Закрытие окна, смена вкладки, потеря фокуса и удаление исходного Tool отменяют перенос. Выбранный слот и выбранная вкладка имеют светлый кант. На узком низком экране хотбар перестраивается, сохраняя все десять слотов и зазор от окна; новых категорий или входов не добавлено.

## Окно Merge Pets

Окно показывает всех питомцев выбранного вида: короткие ID, модели, состояние On base/Backpack. Select выбирает или снимает запись; выбрать можно ровно три, остальные кнопки блокируются. Confirm Merge доступна только для трёх выбранных и передаёт три полных ID; изменившийся набор подтвердить нельзя. Старые TestChick объединяются только с TestChick, сохраняя kind и доход; обычные Chicken считаются отдельно. Пустое окно без инструкций. Есть предупреждение о размещённых питомцах, которые перестанут приносить доход. До отправки Cancel и крестик ничего не расходуют; после отправки Confirm/Cancel заблокированы до ответа, крестик закрывает окно без отмены запроса. На низком экране список прокручивается в оставшейся высоте. В Inventory подтверждения Merge нет.

## Обязательные проверки при изменениях

Автопроверка серверной части — `tools/verify-backpack.luau` (см. [verification.md](verification.md)).

1. Выбор карточки берёт реальный Tool в руку и не размещает питомца на базе; повторный выбор снимает его.
2. Размещённый питомец отсутствует в Backpack; снятый с базы появляется с прежним ID.
3. Несколько питомцев и яиц доступны одновременно; выдача нового предмета не удаляет предыдущие.
4. Полевые и размещённые растущие яйца отсутствуют во вкладке переносимых яиц.
5. Перенос между сеткой и хотбаром, замена слота и поиск сохраняют корректный набор Tool.
6. Размещение, Merge, респавн и повторный вход не дублируют и не теряют сохраняемые предметы.

Статус проверок — в [verification.md](verification.md). Схема хранения и перенос прежнего одиночного предмета описаны в [saves.md](saves.md).
