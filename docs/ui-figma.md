# UI: окна из Figma

Часть [ui.md](ui.md): инварианты UI действуют и здесь.

Дизайн — Figma `StealAnEggUI`; окна импортируются плагинами FigBlox или FigmaRobloxUi. Для FigBlox пользователь импортирует окно (Artwork layers: Separate) и кладёт ScreenGui с `Enabled=false` в Studio: `ReplicatedStorage.UITemplates.<Имя>`. Шаблон хранится только в place; Rojo его не удаляет (`ignoreUnknownInstances`). Если шаблона нет, показывается старое React-окно.

Figma: fileKey `ZrP5tdGgBhp0WV0hKhSdRa`, страница `Page 1`; кадры `Hud V2`, `Shop Window`, `Rewards Window`, окна стоят столбцом (x=-1496): Eggs, Pets, Index, Settings, Offline Cash, Trails Shop, Pickaxe Shop, Rebirth. Узлы искать по имени: id меняются. Новое окно собирается клонированием слоёв `Rewards Window` — карточка `Day1`, `BuyBtn`, `Rewards Header`, стиль текста «DAY 1», `ExitBtn`. Группа блока: Stroke, Bottom, Top, Studs, Mask, Inner Stroke, выше иконки и текст. Окно — группа `XFrame` {`Rectangle 3` тело, `Rectangle 4` контур, `MainFrame`, `Header`}. Цвет шапки — семейство кнопки HUD этого окна, строки списков — Dark. Шрифт — Montserrat ExtraBold.

`FigmaTemplate.luau`: `get` ищет шаблон, `scroll` меняет клипующий Frame на ScrollingFrame (слой `ScrollBar` задаёт цвет и толщину), `button` добавляет кнопку-хитбокс (по умолчанию `Hitbox`), `UIClick` и hover/press по UI-09, `setText` пишет текст и его копию `<имя>_Shadow`. Имена слоёв в Figma совпадают с кодом. FigBlox склеивает в одну картинку нетекстовые слои группы, лежащие под её первым текстом; слои над текстом остаются отдельными. Поэтому в группах Figma под иконками, ручками и прочими частями лежит невидимый текст `Split` (размер 1, прозрачный): фон группы склеивается, а всё выше — отдельные Frame. В группах с фактурой `Split` стоит под `Studs`, поэтому `Studs`, `Inner Stroke` и `Mask` приходят отдельно; в `Mask` под `Split` остаются полутона `Halftone`, выше — `Shine1…`, `SunBurst`, `Cash1…`, `Energy1…`, `PetsIcon`. В Figma эти слои смешиваются Soft Light/Luminosity, которых в Roblox нет: отдельные слои приходят в обычном режиме, их прозрачность подбирает код. `Figma.get` удаляет `Split` из шаблона при первом использовании.

Trails Shop (`TrailsShop.luau`, шаблон `TrailsShop`): App рендерит его внутри `ModalTransition` вместо `UI.Surface` с шапкой; блокер, переход и Escape общие. Окно 1301×720 масштабируется под `windowW×windowH`. По карточке `ShopItemN` на каждый `GameConfig.Trails`; цвет и картинка карточки — из шаблона, новый трейл требует нового импорта. Код меняет `Title`, `Value`, `Condition` (недостаток — `FEE545`), `Label` кнопки `BuyEquipmentN` и `Balance`. Кнопка нажимается для покупки при достатке Cash или для экипировки купленного; при `busy` и закрытии не нажимается. `ExitBtn` закрывает окно. Прокрутка горизонтальная.

HUD (`FigmaHud.luau`, шаблон `Hud`, кадр `Hud V2` 1920×1080) — только широкий экран; компактный экран оставляет React HUD. Импорт хранит размеры в пикселях Figma: корень `FigmaHud` получает один UIScale `min(width/1920, height/1080)`, группы `LeftSideButtons`, `RightSideButtins`, `Counters` стоят в координатах дизайна: левая колонка прижата влево, правая — вправо, обе по вертикальному центру экрана (левая — вместе с рядом Slow Mode/OpenInventory под ней, 12 + 44 единиц UI, `leftReserve`); `Counters` прижаты к левому нижнему углу. Хитбоксы носят имена прежних кнопок: `OpenShop`, `OpenIndex`, `OpenSettings`, `OpenPets`, `Eggs`, `GetSpeed` (Shop → Speed Packs), `GetCash` (Shop → Cash Packs). `Rewards` открывает окно Rewards (хитбокс `OpenRewards`); `Rebirth` открывает окно Rebirth (хитбокс `OpenRebirth`); окно использует шаблон `Rebirth` и `FigmaRebirthWindow.luau`. Счётчики `SpeedValue` и `CashValue` показывают Speed и Cash числом, без множителя и дохода в секунду; кнопки `+` код переносит на x=312, правее поля текста (80..304), чтобы длинное число их не перекрывало.

Видимость: правая колонка скрыта (`Visible=false`), пока открыт Sidebar (UI-05); счётчики скрыты при открытом Inventory; при Offline Cash HUD не рисуется. Остаются React-элементы: `SlowMode` под кнопкой Shop левой колонки (x=19, на 12 ниже её низа в координатах Figma), `OpenInventory` справа от SlowMode (UI-02), таймер лавы (`LavaTimer`), Auto Swing и хотбар.

Shop (`ShopWindow.luau`, шаблон `Shop`, кадр `Shop Window`, из него `ShopFrame` 975×675): App рендерит его внутри `ModalTransition` вместо React-магазина; вкладок нет. `MainFrame` становится вертикальным ScrollingFrame. Карточки сеток `SpeedPacks` и `CashPacks` названы ключами `Config.Offers`, кнопка цены — `Buy_<ключ>`; цены и количества нарисованы в шаблоне, код их не меняет. Starter Pack, 2X Speed (своих предложений нет) и 2X Cash (`cash2`) нажимаются через `BuyBtn`. Все кнопки покупки вызывают общий `purchase`: при ID=0 — сообщение «This purchase is not available yet.». Кнопки Gift FigBlox при импорте не сохранил; если появятся слои `Gift_<ключ>`, они покажут «Gifting is not available yet.». `ExitBtn` лежит рядом с `ShopFrame`; код переносит его в `ShopFrame` на (896, 8), хитбокс `CloseWindow`. Если FigBlox положил UIScale в `ShopFrame`, код использует его, второй не добавляется. `shopCategory` Speed Packs / Cash Packs прокручивает к заголовку раздела (`GetSpeed`/`GetCash` в HUD), остальные — к началу.

Index (`IndexWindow.luau`, шаблон `Index`, кадр `Index Window`, `IndexFrame` 1240×666): на широком экране App использует Figma-окно внутри общего ModalTransition; компактный экран сохраняет адаптивный React Index. `ExitBtn` закрывает окно. `IndexCollection` клонируется по биомам Forest/Desert/Snow/Titanic в вертикальный `IndexScroll`; карточки строятся только по `Config.Pets`, открытия — по `DiscoveredPets`. Закрытые виды показывают «???» и лапу из шаблона; открытые — модель питомца. Выбор карточки обновляет имя, редкость, базовый доход и модель справа. Счётчики биомов, заливки прогресса и общий UNLOCKED берутся из коллекции игрока, а не примерных чисел макета. Награда Forest вызывает прежний `ClaimCollectionReward` только при полной коллекции, без busy и после завершения открытия; CLAIMED определяется серверным атрибутом. При импорте FigmaRobloxUi изображения с ZIndex=0 в этом шаблоне приведены к ZIndex их контейнера, чтобы они не скрывались под фонами.

Eggs (`EggsWindow.luau`, шаблон `Eggs`, кадр `Eggs Window`): `GrowingEggs.luau` рендерит его внутри `RightSidebar` (`UI.Transition`, выезд справа) вместо React-панели; имя `EggsSidebar`, UI-01…UI-05 не меняются. Клонируются `EggsFrame` и вкладка `CollapseSidebar` слева от него; масштаб — общий для правых панелей `Figma.sidebarScale`: 90% от вписывания панели в границы прежней React-панели Eggs (480×460 единиц UI, меньше на узком и низком экране); он же даёт верх панели (по центру, не выше 96). Отступ справа 16. `GrowingEggsScroll` — вертикальный ScrollingFrame; `GrowingEgg1` служит шаблоном строки, по копии на каждое растущее яйцо с шагом 126, код меняет `Name` и `Status`. В шаблоне строки нет слоя иконки: код добавляет `Icon` 84×84 в левый отступ (14, 14) с `Assets.egg` (default-egg). `Condition`: «No eggs on your base» / «Need $X more» / «Hatch N eggs»; `Price` в `GrowAllEggs` — `Config.GrowAllCost`. Кнопка `GrowAllEggs` нажимается, только если яйца есть, Cash хватает и нет `busy`; `CollapseSidebar` закрывает панель.

Pets (`PetsWindow.luau`, шаблон `Pets`, кадр `Pets Window`): `Sidebar.luau` рендерит его внутри `RightSidebar` вместо React-панели; имя `PetsSidebar`. Клонируются `PetsFrame`, вкладка `CollapseSidebar` и `EquipBestPets` под панелью; масштаб, верх и правый отступ те же, что у Eggs (`Figma.sidebarScale`): панели одного размера и выезжают в одном месте. На низком экране масштаб уменьшается, чтобы Equip Best поместился. FigBlox называет текстовые слои их текстом; `Figma.nameTexts` переименовывает их сверху вниз: `Title` и `Label` (`AddPetSlot`) в шапке, `Condition` в `MainFrame`, `Name` и `Income` в строке. `InventoryPet1` — шаблон строки (шаг 126); красный вид кнопки Unequip берётся из `PetAction1` строки 1, зелёный Equip — из `PetAction3` строки 3; код копирует цвета, градиенты, обводки и картинки слой в слой по именам. Иконка питомца (`Assets[pet.icon]`) кладётся поверх лапы, нарисованной в фоне строки. Кнопки: `PetAction<i>` → `EquipPet`/`UnequipPet`, `AddPetSlot` (не при максимуме и нехватке Cash), `EquipBestPets`, `CollapseSidebar`; при `busy` не нажимаются.

Rewards (`RewardsWindow.luau`, шаблон `Rewards`, кадр `Rewards Window`, из него `RewardsFrame` 975×672): App рендерит его внутри `ModalTransition`; `ExitBtn` переносится к `RewardsFrame`, хитбокс `CloseWindow`. `DailyReward` — кнопка `ClaimDaily` (`ClaimDailyReward`), подпись `CLAIM!` или таймер до открытия. `DaysFrame` заменяется горизонтальным ScrollingFrame: на каждый день `GameConfig.StreakRewards` клонируется карточка шаблона по виду награды (Speed — `Day1`, Cash — `Day2`, Egg — `Day3`, Chest — `Day4`) с шагом сетки шаблона; заголовок `DAY N`, кнопка `ClaimDay<N>` (`ClaimStreakReward`). Подписи: `CLAIMED` (карточка затенена), `CLAIM` или таймер до следующего дня (кнопка затенена); у более поздних дней кнопка скрыта. Кнопка Daily не затеняется. Подписи ужимаются до размера дизайна. Таймеры по `workspace:GetServerTimeNow()`, обновление раз в секунду; правило серии — общий `GameConfig.rewardStreak`. При открытии и после получения ряд прокручивается к следующему дню. Анимации: шапка-конвейер, Shine карточек, вращение SunBurst в `DailyReward` (её Mask — CanvasGroup), покачивание `Icon`, каскад появления, наведение и отскок кнопок; Shine в кнопках неподвижны.

Settings (`SettingsWindow.luau`, шаблон `Settings`, кадр `SettingsFrame` 899×754): App рендерит его внутри `ModalTransition` вместо React-окна, масштаб `min(windowW/899, windowH/754)`; крестик — `ExitBtn` шаблона, хитбокс `CloseWindow`. Тексты строк переименовываются `Figma.nameTexts`: `Title`, `Percent`, `Description` у громкости, `Title`, `State` у переключателей. Переключатель (`ViewOthersPets`, `ViewMyPets`, `ViewMyEggs`, `ReducedMotion`) шлёт `SetSetting`; вид ON и OFF берётся из строк шаблона. Если в `Toggle` есть слоистые `Track` и `Knob`, код заменяет их копиями другого состояния и сдвигает `Knob`; плоский `Toggle` меняет картинку. Громкость (`MusicVolume`, `SFXVolume`): клик или перетаскивание по хитбоксу над дорожкой, `Percent` показывает значение сразу, `SetSetting` уходит при отпускании; потеря фокуса отменяет. Если в строке есть отдельные `Track`, `VolumeFill` и `Knob`, ручка встаёт центром на значение (не выходя за дорожку), а `VolumeFill` обрезается до неё (обе строки берут слои самой широкой заливки шаблона, нарисованной на 100%); в Figma части слайдера лежат прямо в строке, без группы; если FigBlox склеил их в одну картинку `Slider`, картинка не меняется. Клавиш Left/Right и прокрутки нет: окно масштабируется целиком.

Offline Cash (`OfflineWindow.luau`, шаблон `OfflineCash`, кадр `OfflineFrame` 1000×640): App рендерит его внутри `ModalTransition` вместо React-окна, масштаб `min(windowW/1000, windowH/640)`. `Amount` — сумма `$N` внутри RichText-тега размера из дизайна; `ClaimOffline` шлёт `ClaimOffline` и закрывает окно после успешного ответа, при `busy` подписан «CLAIMING...» и не нажимается. `DoubleOffline` и бейдж 2x — оформление без действия. Своего крестика в импорте нет: `ExitBtn` из шаблона `TrailsShop` в правом конце шапки, хитбокс `CloseWindow` закрывает без получения.

Движение (`FigmaTemplate`, значения в `Theme.motion`): `button` — hover/press по UI-09, `pulse` — короткий отскок (переключатели Settings при смене состояния). `reveal` — карточки и строки появляются каскадом из 0.7 с отскоком (Shop, Trails Shop, строки Pets/Eggs/Settings, группы HUD при входе и при возврате правой колонки и счётчиков). `idle` на общем Heartbeat: `sway` покачивает картинку предмета (Trails `Image`, слой `Icon` карточек Shop, иконки питомцев, пачка Offline Cash), `spin` вращает `Burst` и лучи `SunBurst` кнопок HUD, `fall` бесконечно роняет картинки `Cash<N>`/`Energy<N>` в `Mask` кнопки Shop (по кругу через высоту маски, с покачиванием), `shine` раз в 4 с проводит полосы `Shine<N>` через маску. `conveyor` (`Figma.studs`, во всех окнах) двигает слой `Studs` в `Header` влево лентой: картинка уходит на смещение по модулю периода плитки (`studsPeriod` 58.8 — плитка 420 px × 0.14 в Figma), справа обрезанная копия, сдвинутая на период. В Figma у Studs шапок нет скругления, иначе на шве видна выемка; без отдельного слоя Studs (старый импорт) лента не включается. `Mask` внутри кнопки становится CanvasGroup и всегда обрезает: ClipsDescendants не работает при наклоне предка. В Figma у `Mask` кнопок HUD и у кадра `Hud V2` снят Clip content, чтобы FigBlox выгрузил вращающиеся и падающие картинки целиком; Halftone лежит в своём обрезающем фрейме `Halftone`. `idle` стоит, пока объект скрыт или его окно проявляется/гаснет (изменения внутри CanvasGroup перерисовывают её), и продолжает со своего места. Картинки `UITemplates` предзагружаются при старте клиента (`ShopUI.client`). ReducedMotion выключает всё это. Иконки карточек Shop в Figma — отдельные слои `Icon` над текстом карточки, иначе FigBlox вклеивает их в фон.

Сборка шаблона защищена `pcall`: при несовпадении имён в консоли предупреждение «Figma template …», окно остаётся пустым, остальной UI работает. Отсутствующие необязательные слои пропускаются через `FindFirstChild`.

Rebirth: `FigmaRebirthWindow.luau`, шаблон `Rebirth`, кадр `RebirthFrame` 975×668. Данные, подтверждение, подбор текста и анимации — в [ui-rebirth.md](ui-rebirth.md).
